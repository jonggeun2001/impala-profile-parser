# Third-party source and dependencies

## Apache Impala generated Thrift types

`src/impala_profile_parser/vendor/` contains the RuntimeProfile dependency closure
from the official `impala-shell 4.6.0` source distribution published on PyPI.
The upstream files were generated by Apache Thrift Compiler 0.16.0.

Only the import namespace was changed from `impala_thrift_gen` to
`impala_profile_parser.vendor`. Generated field IDs and types are unmodified.
Modules included: ErrorCodes, ExecStats, Metrics, RuntimeProfile, Status, Types.

The exact source URL, archive SHA-256 and transformation are recorded in
[`thrift-source.json`](docs/reference/thrift-source.json). Reproduce using
`python3.9 scripts/vendor_thrift.py`; the saved checksum is required to match.

Apache Impala is licensed under Apache License 2.0. The complete upstream source
distribution license notices are preserved in [APACHE-IMPALA-LICENSE.txt](APACHE-IMPALA-LICENSE.txt).
The upstream archive does not contain a separate top-level NOTICE file.

The newer generated reader is used for wire compatibility; our target remains
CDP 7.1.7 / Impala 3.4.0. No Cloudera proprietary binaries or libraries are bundled.
